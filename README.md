# Controle de Dívidas

Aplicação web simples para organizar e acompanhar contas mensais, inspirada em uma planilha de controle financeiro pessoal.

🔗 **Acesse aqui:** https://jaymeda14.github.io/controle-dividas/

## Funcionalidades

- Cadastro de dívidas com nome, valor e dia de vencimento
- Listagem organizada por dia do mês (ordem crescente)
- Marcar dívidas como pagas ou pendentes
- Exclusão de dívidas
- Resumo automático: total do mês, total pago e total em aberto
- Dados salvos no navegador (localStorage) — nada se perde ao recarregar a página

## Tecnologias

- HTML5
- CSS3
- JavaScript puro (sem frameworks ou bibliotecas)

## Como rodar localmente

1. Clone o repositório
   ```
   git clone https://github.com/Jaymeda14/controle-dividas.git
   ```
2. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server no VS Code)

## Sobre o projeto

Projeto criado como prática de desenvolvimento front-end, focado em manipulação do DOM, persistência de dados com localStorage e organização de código em JavaScript.
